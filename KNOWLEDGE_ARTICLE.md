# RoamScope | Endpoint Wi-Fi Roaming & RF Diagnostics

## Purpose
RoamScope is a lightweight Python-based client-side WLAN telemetry and roaming survey tool. It samples the **associated endpoint** to track SSID, BSSID, RSSI, noise (when available), SNR, channel, band, primary-channel frequency and PHY transmit rate (when available). It detects observed BSSID transitions and produces HTML and CSV reports.

## When to use it
Use RoamScope to investigate endpoint roaming patterns while walking between AP coverage areas, to correlate the endpoint's observations with controller/cloud telemetry (such as Mist), and to standardize evidence collection across locations. It is **not** a packet capture, predictive RF survey, or measurement of actual roaming interruption time.

## Architecture
- **macOS:** Python collector reads Wi-Fi data from a locally built Swift CoreWLAN helper via a loopback HTTP endpoint on `127.0.0.1:18763`. Location permission may be needed for SSID/BSSID. Keep the helper open.
- **Windows:** Python collector uses Windows Wi-Fi telemetry; no Swift helper. Windows stationary collection passed a short single-AP check; AP-to-AP roaming remains pending.
- **Outputs:** Local HTML report and timestamped CSVs; keep survey data out of source control.

## Technician quick workflow
1. Use the relevant PDF in `docs/` to install approved Python and dependencies.
2. Connect to the target Wi-Fi SSID and run `--doctor`; **do not** proceed without a real BSSID.
3. Record survey start/end times and client Wi-Fi MAC, then walk a planned route.
4. Run `--duration 0 --interval 2 --csv` for a manually ended survey (Ctrl+C) or choose a fixed duration.
5. Review report, samples and roaming events; compare BSSID transitions with infrastructure telemetry in the **same time zone and time window**.

## macOS commands (from repository root)
```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cd RoamScopeHelper && bash ./build.sh && open ./RoamScopeWiFiHelper.app
# In the helper: Request Location Access (if needed), Read Wi-Fi; leave it open.
cd ..
curl --noproxy '*' --max-time 5 http://127.0.0.1:18763/
python roamscope.py --doctor
python roamscope.py --duration 0 --interval 2 --csv
```

## Windows PowerShell commands (from repository root)
```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
netsh wlan show interfaces
.\.venv\Scripts\python.exe roamscope.py --doctor
.\.venv\Scripts\python.exe roamscope.py --duration 0 --interval 2 --csv
```

## Validation status (October 2026)
- macOS pilot: working SSID/BSSID collection and nine observed BSSID transitions aligning closely with a nine-event Mist cluster (0–2 seconds in the compared displayed times). This supports endpoint roaming-event detection; it does not validate every RF field, per-event 802.11r negotiation, or outage duration.
- Windows: short stationary check passed with 10/10 valid connected BSSID samples over approximately 18 seconds, using Native Wi-Fi. CSV/SQLite counts and generated HTML content checked. AP-to-AP roaming and browser display confirmation remain pending.
- Neighbor scan export may be empty on macOS; do not infer neighbor AP quality from missing data.
- Labels such as `sticky` and `fast` are RoamScope heuristics, **not** equivalent to Mist classifications or proof of 802.11r Fast Transition.

## Troubleshooting
- `python` not found: activate the virtual environment or call its Python executable directly.
- macOS `--doctor` has no BSSID: verify helper is open, location permissions, and `curl` on port 18763.
- Windows no BSSID: compare `netsh wlan show interfaces` and `--doctor`; check adapter/driver support.
- Demo `HomeNet` values: generated by `--simulate`; never use simulation for real surveys.
- Two-second polling detects observed changes, not precise roam start/end times.

## Privacy / publication
Treat client MAC addresses, BSSIDs, SSIDs, survey reports, and internal AP names as potentially sensitive. Do not commit live survey exports, credentials, internal screenshots, or production configuration. Confirm organizational approval and intellectual-property ownership before publishing externally.
